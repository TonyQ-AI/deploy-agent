# 新项目接入决策指南

> 判断新项目应该用哪套部署通道，30 秒定位。
> 本系统（deploy-agent）**仅适用于内网/局域网服务器**。
> **云服务器（公网可达）不适用本系统**，直接用 GitHub Actions 标准 CI/CD 即可（无需自建）。

---

## 一句话结论

```
服务器在局域网（SMB 可达）→ 用本系统（deploy-agent）
服务器在云上（公网可达）   → 直接用 GitHub Actions（本系统不适用）
```

> 理由：GitHub Actions 依赖服务器公网可达（SSH/SCP 直接进），云服务器天然满足；
> 本系统解决的是"Actions 进不来的内网场景"。云场景用 Actions 更优（构建隔离、免费、标准），
> 自建云版本属于画蛇添足。

---

## 三问判断法

```
新项目接入
│
├─ Q1：服务器能通过局域网 SMB 访问吗？
│     （自己家/办公室的旧电脑，\\服务器\共享 能打开）
│     ├─ 能 → 🅰 方案 A：SMB + watcher（当前模式，3 秒即时）
│     └─ 不能（云服务器/异地）→ Q2
│
├─ Q2：服务器是 Windows 系统吗？
│     ├─ 是 → 🅱 方案 B：SCP/OSS 传输 + watcher（脚本几乎原样）
│     └─ 否（Linux）→ 🅲 方案 C：Git 驱动 + systemd
│
└─ 补充：部署延迟要求
      ├─ 秒级 → A/B（watcher 触发）或 C 用 Webhook
      └─ 分钟级可接受 → C 用 systemd timer 轮询 git
```

---

## 方案对照表

| 判断维度 | 🅰 局域网 SMB | 🅱 云 Windows | 🅲 云 Linux |
|---------|--------------|--------------|-----------|
| 传输通道 | SMB 共享 | SCP/OSS | **git 本身** |
| 部署触发 | 写标志 → watcher | 写标志 → watcher | git push 即信号 |
| 服务器动作 | watcher.ps1（原样）| watcher.ps1（原样）| systemd timer / webhook |
| 重启 | restart.cmd | restart.cmd | restart.sh（systemctl）|
| 兜底/自愈 | daily-check.ps1 | daily-check.ps1 | systemd 天然自愈 |
| 代码/产物同步 | robocopy | scp / ossutil | git pull（产物入库或 CI）|
| 即时性 | ≤3 秒 | ≤3 秒 | webhook 秒级 / 轮询分钟级 |
| 前提条件 | 局域网 + SMB 共享 | 云开 SSH / OSS | GitHub 可访问 + systemd |

---

## 关键判断依据

1. **服务器在哪**（首要）→ 决定传输通道：SMB / SCP / git
2. **操作系统** → 决定服务器动作实现：PowerShell + 计划任务 vs systemd
3. **产物策略** → 方案 C 要求 dist 等产物入库或 CI 构建（gitignore 需调整）；
   A/B 产物走传输通道（gitignore 不变）
4. **即时性** → 秒级选 watcher（A/B），云上可选 Webhook；分钟级可用轮询（最简单）

## 各方案接入步骤差异

| 步骤 | 🅰 局域网 | 🅱 云 Windows | 🅲 云 Linux |
|------|---------|-------------|-----------|
| 服务器装环境 | 拷贝 node/cloudflared | 装 node + 开 SSH | 装 node + systemd |
| projects.config | 加一行 | 加一行 | 不需要（Git 驱动）|
| restart 脚本 | restart.cmd | restart.cmd | restart.sh |
| 计划任务/服务 | watcher + daily（bat 注册）| watcher + daily（bat 注册）| systemd timer + service |
| 本机 deploy.ps1 | robocopy + 写标志 | scp + ssh 写标志 | git push（+ CI 可选）|
| 文档 | 主文档 | 适配：传输命令 | 适配：Git 驱动 |

## 决策速查（常见场景）

| 场景 | 推荐方案 |
|------|---------|
| 家里旧电脑当服务器（局域网）| 🅰 SMB + watcher |
| 阿里云 Windows ECS | 🅱 SCP + watcher |
| 阿里云 Linux ECS（Ubuntu/Debian）| 🅲 Git 驱动 + systemd |
| 腾讯云/华为云 类似 | 按系统选 🅱/🅲 |
| 需要秒级部署的云服务器 | 🅱（ssh 触发）或 🅲 + Webhook |
| 部署不频繁、延迟不敏感 | 🅲 轮询（最简单）|
